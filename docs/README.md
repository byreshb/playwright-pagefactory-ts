# Docs

Start here if the code feels confusing. Read in this order:

1. [`syllabus.md`](syllabus.md) — a step-by-step learning path, from "what is a page object" to "how the decorators work".
2. [`reading-the-code.md`](reading-the-code.md) — a file-by-file map of `src/`, with the order to read it in.
3. [`what-is-what.md`](what-is-what.md) — what this project created versus what Playwright (and other libraries) already provide.
4. [`dependencies.md`](dependencies.md) — every dependency and config choice, and why it's there.
5. [`constructor-vs-decorators.md`](constructor-vs-decorators.md) — page objects via constructors, via decorators, or both together.
6. [`how-the-factory-works.md`](how-the-factory-works.md) — the actual logic: how decorated classes become working page objects.

The whole library is about 150 lines across 6 small files. You can read all of it in 20 minutes.
